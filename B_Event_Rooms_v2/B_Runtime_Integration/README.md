# B · 22间体素事件房接入

A2游戏进入22种正式事件房时加载对应GLB。角色移动、战斗、E互动、对白、费用、收益、完成状态与存档继续由原系统负责。

## 运行

使用Godot 4.6.3导入`game/project.godot`并运行Main。房间按原等级与事件池出现，未修改事件投放和解锁规则。单独的Windows试玩包包含同版本运行时、正式压缩PCK和独立player-data目录。

## 接入内容

- `game/assets/B_event_rooms/`：共享墙地GLB和22组事件部件；检修口保留实际地板开孔。
- `game/data/assets/B_event_rooms.json`：22个正式事件ID、互动点、实体占地、掉落点与组件深度。
- `game/scripts/presentation/B/`：模型目录与3D视口渲染器。
- 2D角色与3D地面使用同一归一化坐标；前景模型按玩家位置遮挡角色，角色保持原比例。
- 模型门随真实可通行、地图边界、标记及战斗锁定状态开合；烛光轻微变化，事件完成后出现状态提示。
- 陈设与模型碰撞同步。接入时将预支房柜台前移0.55米，将围笼两侧辅助设备移到前侧，留出可走通的入口；原v2预览保留，运行版几何以游戏GLB为准。
- 离开模型房释放视口和模型；切回旧房间恢复原精灵。普通房、宝箱房等仍使用A2现有表现，本轮新增GLB覆盖22类事件房。

## 验证

Godot 4.6.3下逐房运行检查528项通过，包括22个模型加载、3D投影与角色坐标对齐、陈设碰撞、四门与服务点可达、门锁状态及切房清理。PCK内再次运行同一528项检查通过。

实际从压缩PCK运行Main，进入减压事件房，通过E打开原对白并完成服务：余额9→4，压力40→35；过期报价拒绝与退出后恢复移动均通过。截图来自实际打包版。

现有A2事件、经济、流程、信息、掉落、探索、UI回归均按检查记录执行；保留26类旧PNG事件房测试，并为已转GLB的旅商、骰局和祭坛验证新后端。工程引用静态检查2052个文件，错误和警告均为0。正式PCK通过脚本校验、Main新建/保存及独立进程恢复。
