# 事件房渲染参考 v2

B23—B44共22间，每间提供一张1920×1200实际Blender渲染及可编辑源场景。保留v1。采用统一正面正交机位、灰青石材与暖烛光。

## 逐房修改

- **B23**：线报桌、档案架、纸箱和座椅组成查阅区。
- **B24**：足浴盆、座椅、供水管、毛巾架和休息凳组成休息区。
- **B25**：急救柜配药品架与药箱推车。
- **B26**：祭坛两侧改为供物与蜡烛。
- **B27**：回收台两侧分别布置待回收与分拣料箱。
- **B28**：补给台后方增加成组货架，前方保留交易空间。
- **B29**：起爆器增加下压手柄、加固底座、后挡板和引线；工具与线轴集中收纳。
- **B30**：登记桌、资料架、纸箱与座椅集中。
- **B31**：机关柜两侧分别放工具架和零件箱。
- **B32**：线圈旁配置线轴架、工具架和材料箱。
- **B33**：压机居中，左侧原料推车、右侧压缩成品推车，工具架靠后。
- **B34**：博弈桌保留正面交互空间，休息凳靠边。
- **B35**：检修入口改成实际地面开口、下行台阶与竖起的盖板。
- **B36**：托运机增加接收腔、包裹托盘、铜管及支撑，待运包裹集中在推车。
- **B37**：旅商改为带车轮、折叠棚和前柜台的便携货车，货物分开放置。
- **B38**：修包台突出立式背包、肩带、扣件、布料架。
- **B39**：储蓄装置改为带面具造型、投入口与取物盘的守库机关。
- **B40**：侦察台配资料架和工具架。
- **B41**：围笼放大并居中，四角立柱与前侧入口明确，四个房间出口独立保留。
- **B42**：档案室增加五组书架，登记台居中，留出通行与查阅间距。
- **B43**：预支室改为契约台、秤、印章及两组带锁押物架。
- **B44**：骰局桌配记账桌和旁观休息凳。

## 交付与验证

撤去按关键词套用的散落杂物，逐间定义主装置、配套与收纳位置。复用组件包括书架、药品架、布料架、工具架、材料箱、推车、长凳、押物架；检查JSON记录各工位对象及世界包围盒。B1—B22原资产保持原样。

22张图均可解码、尺寸一致且内容哈希各异；22份源场景重新打开，贴图引用与相机数据正常。22间跨组件与墙体/壁龛AABB筛查均无候选，已查看全体缩略图及重点房间大图，修正旅商货车内部货物间距。此检查不等于所有内部网格、运动扫掠及引擎碰撞已验收。

新增部件仍是视觉确认用预览模型，尚未交付正式模块GLB、动作片段或游戏接入。本批未上传。
